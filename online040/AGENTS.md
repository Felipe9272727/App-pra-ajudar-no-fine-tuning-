# Online040

User requests the same context and generation budgets in the public Space and
the Android app, and direct Hugging Face GPU inference from the Android selector.
Preserve the installed 0.6.3 app data, assets, prior signed releases and all weights.

The new main APK is a same-package, same-certificate update to versionCode 8.
The updater is version 0.4 of the smaller installer package. It reuses only
verified APK assets and hands the exact rebuilt APK to PackageInstaller with
normal user confirmation. Never bundle a token, key or credentials in artifacts.
The project owns the fixed HTTPS endpoint and tests it on real ZeroGPU. An
optional personal read token stays encrypted on the user's device. GPU mode has
its own history. Local modes preserve the existing tools and inference engines.

Keep provider quota behavior visible and distinguish shipped token budgets from
actual sampled output. No change to model weights. Record all installation and
Space validations and preserve any failure evidence.
