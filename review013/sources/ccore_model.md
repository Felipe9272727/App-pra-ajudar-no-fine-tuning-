# CCORE GLB-3D-Coder

### Turn a text prompt into an editable 3D asset.

**CCORE GLB-3D-Coder** is a specialized **4B coding model** for low-poly game assets and procedural scenes. Describe a character, prop, building, or environment, and the model writes a complete **Three.js HTML/JavaScript page** with a preview and an **Export GLB** button. Open the page, inspect the result, and export the asset for **Godot or another editor that supports GLB**.

**CCORE project release · November 5, 2026 · Apache 2.0**  
Repository: `ccore/Qwen3.5-4B-GLB-3D-Coder` · Checkpoint: latest uploaded

This independently developed CCORE model was trained using [Qwen/Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B) as its base. CCORE maintains this release.

**Q4_K_M, Q8_0, and the original Safetensors weights are available now.**

**The training dataset has also been released:** [**CCORE ThreeJS-3D-GLB-Assets**](https://huggingface.co/datasets/ccore/ThreeJS-3D-GLB-Assets) — **3,918 tested and rendered examples across 40 domains, with validated GLB exports.**

**Important:** If you downloaded the model before **November 5, 2026**, **delete the old model files and download them again** in LM Studio or whichever app you use. The GGUF filenames haven't changed, so make sure you're loading the updated weights.

## Quick start

1. Load a GGUF in a runtime that supports Qwen3.5, or load the original checkpoint with its configuration, tokenizer, and chat template.
2. Set the **system prompt** and **sampling parameters** below.
3. Send an English asset request. Start with a short idea, or specify the parts, materials, colors, layout, and animation you need.
4. Save the complete generated HTML as an `.html` file and open it in a browser. The page may load Three.js and its add-ons from a CDN.
5. Inspect the scene, click **Export GLB**, and import the downloaded `.glb` into your editor.

Request animation explicitly when you need it, and check that it is included in the exported GLB.

### Sampling settings

| Parameter | Value |
|:---|:---|
| Temperature | **0.8** |
| Top K | **40** |
| Top P | **0.95** |
| Min P | **0.0** |
| Repeat penalty | **1.0** |

The recorded evaluation used these settings with thinking enabled. Allow enough output tokens for the complete HTML; detailed scenes can produce long responses.

### Output length and thinking

| Parameter | Recommended setting |
|:---|:---|
| Maximum output tokens | **Unlimited — `-1` where supported** |
| Thinking / reasoning | **Enabled, with no effort limit or separate thinking-token budget** |

**Allow the model to finish generating.** The model was trained on examples reaching **72K tokens**. Responses average around **20K tokens**, and some can be longer.

**An 8K output limit is too restrictive for these generations** and can stop the response during thinking or before the HTML is complete, leaving incomplete or unusable code. Set the output limit to **unlimited (`-1`)** in runtimes that support it.

**Keep thinking enabled, without limiting reasoning effort or imposing a separate thinking-token budget.** I have not validated generation quality with thinking disabled, truncated, or restricted.

Unlimited output removes the explicit generation cap; the runtime's context and resource limits still apply.

### System prompt

```text
Create game assets for the Godot editor, which uses GLB files. Create whatever the user requests as a good-quality low-poly asset using only Three.js in one complete standalone HTML file. The HTML must show the asset and include an Export GLB button that downloads a working GLB. If the requested asset needs animation, add it and include the animation in the exported GLB; otherwise make it static.
```

## Current limitations

Some requests need a retry or a small code correction. Inspect the exported asset in your editor, since materials, lighting, and animations can differ from the browser preview.

## What comes next

The training dataset is now publicly available: [**CCORE ThreeJS-3D-GLB-Assets**](https://huggingface.co/datasets/ccore/ThreeJS-3D-GLB-Assets). Beyond this release, I want to build **larger, carefully reviewed datasets** and **more capable small models**, including specialized models in other areas.

I've developed and funded this work myself, and I'm releasing the **models, weights, and datasets free of charge to the community**.

Next, I'm planning **100,000 high-quality examples for 3D and general-purpose coding harnesses** to **train new small models** that can use tools, test their outputs, and refine their work through iteration.

I expect **creating these datasets and training the new models to require around 20 times the effort of the current project**. **I need the community's support to make this next stage possible.**
