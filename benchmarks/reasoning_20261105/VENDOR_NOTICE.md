# Upstream evaluation code

The files in vendor/instruction_following_eval are unmodified Google Research
IFEval sources from commit e6890f85757dd84e27ca6df2dd30651dafad28e0.
They retain their copyright and Apache License 2.0 headers.
Source: https://github.com/google-research/google-research/tree/e6890f85757dd84e27ca6df2dd30651dafad28e0/instruction_following_eval
License: https://www.apache.org/licenses/LICENSE-2.0

LiveCodeBench source data revision and the exact selected private-case indices
are recorded in sources.json and oracles.json. LiveCodeBench dataset metadata
identifies the MIT license. GSM8K data come from OpenAI's grade-school-math
repository at its pinned revision; original test answers are not modified.
No upstream model score is represented as a locally measured score.
